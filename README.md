# MusicBot — Telegram-бот для музыки

## Описание

MusicBot — это Telegram-бот для поиска, прослушивания и добавления музыки. Бот работает как личная музыкальная коллекция: загрузил песню один раз — и она всегда доступна. Все треки хранятся на серверах Telegram, а бот использует локальную базу данных для быстрого поиска.

Проект не использует внешние API для поиска музыки. Все песни добавляются пользователями через MP3-файлы и сохраняются в локальной SQLite-базе.

---

## Возможности

- Поиск песен по названию
- Список всех песен с пагинацией (по 10 песен на страницу)
- Добавление песен через MP3-файлы
- История поиска (последние 10 запросов)
- Воспроизведение прямо в Telegram
- Интерактивное меню с кнопками

---

## Как это работает

Telegram → MP3 файл → SQLite (file_id, название)

Telegram → запрос → поиск по БД → аудио из Telegram

Основной сценарий:

1. Пользователь отправляет MP3-файл боту
2. Бот сохраняет file_id и название в SQLite
3. Песня сохраняется в базу данных
4. При поиске бот ищет совпадения по названию
5. Находит file_id и отправляет аудио из Telegram

---

## Безопасность и ограничения

- Токен бота хранится в отдельном файле config.py (не выгружается на GitHub)
- Все данные хранятся локально в songs.db
- MP3-файлы не скачиваются на сервер — используется file_id Telegram
- Бот работает через официальное Telegram API
- Для доступа к Telegram API в РФ может потребоваться VPN

Ограничения:

- Поддерживается загрузка MP3-файлов
- Размер файла ограничен Telegram Bot API (до 20 MB)
- Без интернета бот не работает (требуется доступ к Telegram API)

## Установка

### 1. Создайте виртуальное окружение

python -m venv .venv
source .venv/bin/activate  # Linux/Mac
.venv\Scripts\activate     # Windows

### 2. Установите зависимости

pip install -r requirements.txt

### 3. Настройте токен в config.py

class Settings:
    BOT_TOKEN: str = "ваш_токен_от_BotFather"

settings = Settings()

### 4. Запустите бота

python main.py

### 5. В случае чего можете 

Обратиться к автору за получением токена

Либо воспользоваться уже готовым ботом: @flndme_bot

## Пример использования

1. Запустите бота: python main.py
2. Откройте Telegram и найдите бота
3. Напишите /start — откроется меню
4. Отправьте MP3-файл боту
5. Введите название песни
6. Готово. Песня добавлена в коллекцию
7. Напишите название — бот найдёт и отправит песню
8. Используйте /list для просмотра всех песен

## Структура базы данных

CREATE TABLE songs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    keyword TEXT UNIQUE NOT NULL,
    file_id TEXT NOT NULL,
    title TEXT
);

- id — уникальный номер песни
- keyword — ключевое слово для поиска
- file_id — идентификатор аудио на серверах Telegram
- title — название песни
