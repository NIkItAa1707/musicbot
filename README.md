\# 🎵 MusicBot — Telegram бот для музыки



\## Описание

\*\*MusicBot\*\* — это Telegram-бот для поиска, прослушивания и добавления музыки.  

Он работает как личная музыкальная коллекция: загрузил песню один раз — и она всегда доступна.



\## Возможности

\- 🔍 \*\*Поиск\*\* по названию и исполнителю  

\- 📋 \*\*Список всех песен\*\* с пагинацией (21 страница)  

\- ➕ \*\*Добавление песен\*\* через MP3-файлы  

\- 📊 \*\*История поиска\*\*  

\- 🎵 \*\*Воспроизведение\*\* прямо в Telegram  

\- 🎤 \*\*Отображение исполнителя\*\* в списке



\## Установка и запуск



\### Требования

\- Python 3.10+

\- Telegram аккаунт

\- VPN (для доступа к Telegram API в РФ)



\### 1. Клонируй репозиторий

```bash

git clone https://github.com/твой-логин/music\_bot.git

cd music\_bot

2\. Установи зависимости

bash

pip install -r requirements.txt

3\. Настрой токен

Напиши @BotFather в Telegram



Отправь /newbot



Скопируй полученный токен



Вставь его в файл config.py



4\. Запусти бота

bash

python main.py

Использование

Команды

Команда	Описание

/start	Открыть главное меню

/list	Показать список всех песен

/add\_song	Добавить новую песню

Отправь MP3-файл боту



Введи название песни



Введи исполнителя (опционально)



Готово! 🎵

Просто напиши название или исполнителя в чат — бот найдёт и отправит.
